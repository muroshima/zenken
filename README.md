# zenken — 全件を見る経費監査エージェント

**AIに任せたのは「人がやっていた作業」ではなく、「人がやれていなかった網羅」。**

経費申請の承認は、実態として上長が目を通して終わっている。1件ずつは見ていても、**過去の全申請と照らし合わせて見ることは誰もやっていない**。重複も、規程からの微妙なズレも、桁の間違いも、見つかるかどうかは運になる。

zenken は全件を過去の全データと突き合わせ、**説明のつくものは自動で通し、説明のつかないものだけ理由をつけて人に渡す**エージェント。

> AI HACK 2026（第2回）提出作品。テーマ「業務を自律化するAIエージェント」。

---

## 何をするか

```
申請を取り込む
   ↓
過去の申請と照合  ──┐
規程と照合        ──┤ エージェントが状況に応じてツールを選ぶ
金額・日付を検算   ──┘
   ↓
判定
   ├─ 説明がつく      → 自動で承認し、根拠を記録する
   └─ 説明がつかない  → 何が引っかかったかを添えて人に渡す
                         ↓
                    人の判断が記録に戻り、次の判定に効く
```

## 設計

主催によるエージェントの定義（モデル / ツール / ループ / 記録）のうち、**モデルと記録は OrcaRouter が担う**。
このリポジトリが設計しているのは **ツールとループ**。

| 要素 | 実装 |
|---|---|
| モデル（判断） | OrcaRouter 経由。申請の難易度でモデルを振り分ける |
| ツール（実行） | 過去照合 / 規程照合 / 検算 / 人に渡す |
| ループ（繰り返し） | 1申請を判定が確定するまで回す。回数とトークンに上限を置く |
| 記録 | 実行をジャーナルに追記する。途中で落ちても再生して再開できる |

## OrcaRouter をどう使っているか

| 機能 | この作品での使いどころ |
|---|---|
| Named Router | 申請の大半は定型（交通費・少額）で安いモデル。金額が大きい・非定型・過去と乖離しているものだけ上位モデルに上げる |
| PII Shield | 申請には氏名・取引先・口座が必ず乗る。モデルに渡す前に落とす |
| Guardrails / Agent Firewall | **領収書の備考欄に指示文を書けば、読んだエージェントを乗っ取れる**。この攻撃を想定して防ぐ |
| Fallback | 締め処理は止まると困る。モデルが落ちても処理を続ける |

## セットアップ

API キーは **macOS Keychain だけを正とする**。リポジトリにも `.env` にも置かない。

```bash
# 一度だけ。値はプロンプトに入力する（画面にはエコーされない）
security add-generic-password -a orcarouter -s orcarouter-api-key -U -w

# 疎通確認
python3 scripts/check_orca.py
```

## 開発

開発中は `orcarouter/free`（無料枠に自動ルーティング）だけを使い、クレジットを消費しない。
有料モデルを使うのは、最終的なコスト実測のときだけ。

```bash
uv sync
uv run pytest
```
